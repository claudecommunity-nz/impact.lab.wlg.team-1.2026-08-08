# Unit 19: 1000-Ticket Dataset

## Objective

Replace the hand-curated 12-incident `incidents.json` with the full
filtered set from `synthetic_tickets_1000.csv` (~389 relevant tickets).
A Python conversion script does the parsing, filtering, mapping, and
severity inference — output is a new `incidents.json`.

## Conversion script (`data/convert_tickets.py`)

1. Parse CSV with `csv.DictReader`.
2. Filter to rows whose `SERVICE_ITEM` matches our 5 mappable values.
3. For the corrupted `"Drinking or Tap waterReport a fallen or dangerous tree"`
   rows: keyword-match `TICKET_DETAIL` to split into `water` or `trees`.
4. Map `SERVICE_ITEM` to category id:
   - `flooding` → `flooding`
   - `Slips` → `slips`
   - `Weather event` → `weather`
   - `road and footpath maintence` → `roads`
5. Infer severity from `TICKET_DETAIL` keywords:
   - high: "burst", "gale", "hail", "rising", "covering", "dangerous",
     "unsafe", "emergency", "blocking"
   - low: "minor", "slight", "small", "cracked", "overgrown", "flickering"
   - medium: everything else
6. Build `description` from address + category label.
7. Write `map/public/incidents.json`.
