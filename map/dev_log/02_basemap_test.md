# Unit 02: Basemap — Test Instructions

## Manual Tests

1. Open `http://localhost:5173` — map fills the full browser viewport, no white margins
2. Tiles load — CARTO Positron streets/labels visible over Wellington
3. Pan by dragging — map moves smoothly
4. Zoom with scroll wheel or pinch — zoom levels change
5. No console errors in browser DevTools

## Success Criteria

- Map fills 100% of viewport
- Wellington city centre visible on load (zoom 12)
- Pan and zoom functional
