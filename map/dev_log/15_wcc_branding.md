# Unit 15: WCC Branding

## Objective

Align the app with Wellington City Council's published brand (primary yellow
#FFDD00, primary black #000000) before demoing to the council.

## Changes

### Header (`Header.jsx`)
- Change the "W" crest from red (`#cf2b1e`) to WCC yellow (`#FFDD00`) with
  black text — red is not part of the WCC brand palette.

### Timeline (`Timeline.jsx`)
- Play/pause button: white emoji → yellow (`#FFDD00`) icon, so the primary
  interactive control reads as on-brand.
- Scrubber `accentColor`: `#fff` → `#FFDD00` so the range thumb and track
  fill match.
